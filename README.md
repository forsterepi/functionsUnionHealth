# functionsUnionHealth

<!-- badges: start -->

<!-- badges: end -->

Package `functionsUnionHealth` contains all functions created for
project “REPONAME”. The functions are extracted to a separate package in
order to make use of the established testing and documentation
infrastructure developed for R packages. Please refer to the Readme of
“REPONAME” for details, which is another Github repository of user
“forsterepi”.

## Installation

You can install the development version of `functionsUnionHealth` like
so:

``` r
pak::pak("forsterepi/functionsUnionHealth")
```
